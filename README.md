## 🚀 About Me

I'm a **self-taught developer from Pakistan** who learns by building things and by taking them apart.

Right now I'm focused on **Full Stack Web Development**, learning to build complete applications from the interface to the server. After that I'm heading into **AI and Machine Learning**, with the long-term goal of becoming an **AI Engineer and Software Developer**.

I'm curious about how things work under the hood. When I use a well-known website or app, I want to know how it was built, and then I try to rebuild it myself. That's where my interest in **reverse engineering** comes from.

- 🔭 Currently learning **Full Stack Development**
- 🌱 Next up: **Python, AI and Machine Learning**
- 🧩 Interested in **reverse engineering** and recreating real-world apps from scratch
- 🤝 Open to **collaborating, internships, freelance work and open-source contributions**
- 💬 Ask me about **web development, learning to code on your own, or how an app is built**
- ⚡ Fun fact: I'd rather work out how something was built than read the docs first 😄
